P. Toolbox v56 · Design Repair

이번 버전은 v54/v55의 동일한 앱 본문을 기준으로, 확인된 회귀 오류를 직접 수정했습니다.

주요 변경
- 테마 패턴은 앱 창 바깥 데스크톱 배경에만 표시하고, 앱 내부 main 캔버스는 단색으로 분리
- 격자 패턴 background-size를 두 레이어 각각 지정해 반복 표시 수정
- PROMPT RANDOM 개별 랜덤 버튼을 OUTFIT RANDOM과 동일한 작은 윈도우 버튼 규격으로 복구
- 로그 뷰어 제목·날짜의 크기와 좌우 정렬을 재정리
- PAIR BOARD 상세 화면을 구조적으로 재정리: 얇은 가로 배너, 두 인물의 균형 잡힌 세로 사진, 간결한 연결 마크, 독립된 기념일 정보 줄, 정돈된 하위 아카이브
- 버전 목록 전체를 유지하는 안정화 렌더러 추가. 같은 게시글의 버전 전환에서는 기존 버튼 DOM을 보존하고 프롬프트/사진 콘텐츠만 전환
- PWA 캐시명을 v56으로 갱신

배포
기존 저장소의 index.html과 sw.js를 교체하세요. 기존 manifest.webmanifest와 아이콘은 그대로 둬도 됩니다.
LocalStorage 및 IndexedDB를 삭제하거나 초기화하지 마세요.

검증
이 패키지는 JavaScript 구문, CSS 파싱, HTML ID 중복, ZIP 무결성을 정적 검사했습니다.
이 실행 환경에서는 file:// 및 외부 브라우저 페이지 네비게이션이 관리자 정책으로 차단되어 실제 터치 테스트는 수행하지 못했습니다.
