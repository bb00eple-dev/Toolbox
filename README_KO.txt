P. Toolbox v43 · GitHub Pages 배포

배포 방법
1. 압축을 풉니다.
2. index.html과 sw.js를 기존 GitHub 저장소 최상위의 동일 파일과 교체합니다.
3. 나머지 파일(manifest.webmanifest 및 PNG 아이콘)은 기존 파일을 유지하면 됩니다. 전체 패키지를 배포한다면 여섯 파일을 저장소 최상위에 둡니다.
4. GitHub Pages HTTPS 주소에서 새로고침합니다. 서비스 워커 캐시가 갱신되도록 한 번 완전히 다시 불러오세요.

데이터 보존
- 기존 방 ID, 로그인 메타데이터, IndexedDB 이름, localStorage 접두사와 페어 로그 저장 구조를 유지했습니다.
- 기존 페어/사진/로그 데이터는 삭제하거나 초기화하지 않습니다.
- 팔레트 사용자 색상은 방별 localStorage에 별도로 저장합니다.
- 비밀글은 PBKDF2-SHA-256으로 키를 파생하고 AES-GCM으로 제목·부제·플랫폼·분류·태그·본문을 암호화합니다. 날짜와 페어 연결 정보는 목록에서 확인할 수 있습니다.
- 비밀글 비밀번호는 복구할 수 없습니다. JSON 백업에는 암호문이 포함됩니다.
- 정기적으로 JSON 백업을 별도 보관하세요.

이번 업데이트
- 페어 로그 편집기에 실행 취소/다시 실행과 Ctrl/Cmd+Z, Ctrl/Cmd+Y를 추가했습니다.
- 글자색/형광펜 공통 팔레트, HEX 입력, 19개 색상 계열, 사용자 색상 저장/삭제를 추가했습니다. 사용자 팔레트는 로그인한 방별로 분리됩니다.
- 글꼴 적용, 굵게/기울임/밑줄/취소선, 제목/인용/코드/목록 서식을 확장했습니다.
- 메모지, 줄노트, 포스트잇, 이메일, 편지, 폴라로이드, 기밀 문서, 영수증, 접이식 섹션 기록물을 본문에 삽입할 수 있습니다.
- 기기 이미지 파일과 HTTPS 이미지 주소 삽입을 지원합니다.
- 비밀글 생성/잠금 해제/편집/비밀번호 변경/일반글 전환 기능을 추가했습니다. 잠금 해제된 본문은 현재 탭의 메모리에만 보관됩니다.
- 기존 페어별 로그 분리, A/B 대화 블록, 사진/페어 기능과 저장소를 유지했습니다.
- 서비스 워커 캐시 버전을 v43으로 갱신했습니다.

주의
- 이 환경에서는 브라우저 자동화 테스트가 관리자 정책으로 차단되어 실제 화면 조작 테스트를 완료하지 못했습니다. HTML 구조 검사와 모든 인라인 JavaScript 구문 검사는 완료했습니다.
