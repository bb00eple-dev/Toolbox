P. Toolbox v51 · Stage 2 Enhancements

v51은 v50의 1차 복구 내용을 포함하고, 사용자가 추가로 요청한 확장 기능을 얹은 버전입니다.

[1차 복구 포함 사항]
- 헤더 제목 한 줄 고정 및 THEME 버튼 크기 조정
- +BOARD/-BOARD 및 Pair Log 툴바 버튼 규격 조정
- Pair Log 팔레트 이벤트 초기화 오류 수정, 색상 적용 및 저장 복구
- 비밀글 비밀번호 입력 UI와 AES-GCM/PBKDF2 암호화 저장·잠금 해제
- 기록물 템플릿 삽입/설정/이동/삭제 및 상태창 기능 연결 복구
- 테마 배경 패턴 표시 수정, 선/간격 색상 별도 지정, 영문+한국어 레이블
- PROMPT RANDOM 한국어 태그명과 자연어 미리보기 보완
- Pair Log COPY TEXT를 본문에서 분리

[2차 확장]
- 하나의 PROMPT BACKUP 글에 여러 프롬프트 버전을 저장
- 버전별 이름 지정, 추가/삭제, 편집 중 버전 전환
- 상세 열람 화면에서 저장된 버전 간 전환
- 기존 versions가 없는 게시글은 기존 prompts 필드를 기본 버전으로 읽음
- Pair Log 글꼴 선택 13종 및 선택 영역 적용
- PROMPT BACKUP, PHOTO GALLERY, Pair 사진, 이미지 자르기 화면에 원본 비율 선택 추가
- 원본 비율은 이미지의 자연 비율로 표시하고, 기존 게시물의 개별 비율은 보존
- Pair Board 로그에 별도 열람창 추가
- 비밀 로그도 올바른 비밀번호 확인 뒤 읽기 전용 열람창에서 표시

배포 방법
1. 기존 GitHub Pages 저장소의 index.html과 sw.js를 이 패키지 파일로 교체합니다.
2. 기존 manifest.webmanifest 및 아이콘은 그대로 유지합니다.
3. 기존 브라우저 저장소(LocalStorage/IndexedDB)를 삭제하거나 초기화하지 마세요.
4. v51의 서비스 워커 캐시 이름은 p-toolbox-shell-v51입니다. 배포 후 앱을 다시 열어 새 캐시가 적용되도록 해주세요.

데이터 호환성
- 기존 Prompt Backup 게시글의 prompts 필드는 그대로 유지됩니다.
- 새 versions 데이터가 없는 글은 읽을 때 기본 버전 한 개로 표시됩니다.
- 사진 비율 설정은 기존 자료를 강제로 변환하지 않습니다. 새로 선택한 원본 비율만 해당 이미지/카테고리에 적용됩니다.
- Pair Log 및 기존 백업의 저장소 키를 초기화하지 않습니다.

검증
- 4개 인라인 JavaScript 구문 검사 및 sw.js 구문 검사 통과
- CSS 파싱 오류 0, 중복 HTML ID 0
- 브라우저 런타임: 프롬프트 버전별 작성 내용 보존, 게시글 저장, 상세 화면 버전 전환, Pair Log 별도 열람창, 글꼴 선택 적용, 원본 비율 렌더링 확인
- v50에서 팔레트 색상 적용, 로컬 이미지 삽입, 비밀글 비밀번호/암호화 흐름, 기록물 템플릿과 상태창, 테마 패턴/선·간격 색상, PROMPT RANDOM 한국어 표시 확인
- 실제 GitHub Pages 배포 환경과 물리적 모바일 기기에서의 통합 테스트는 이 실행 환경에서 수행하지 못했습니다.
