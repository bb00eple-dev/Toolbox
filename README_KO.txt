P. Toolbox v48 배포 파일

[배포]
GitHub 저장소 최상위의 index.html과 sw.js를 교체합니다.
manifest.webmanifest와 p-toolbox 아이콘 파일은 기존 파일을 유지해도 됩니다.

[이번 수정]
- 원본 RP Archive V175의 기록물 템플릿 HTML과 기록물 전용 CSS를 대조해 원본 디자인 규칙을 복구했습니다.
- 메모지, 줄노트, 포스트잇, 이메일, 편지, 폴라로이드, 기밀 문서, 영수증, 접이식 섹션의 원본 템플릿을 유지합니다.
- 기록물 삽입·팔레트 열기·색상 적용 시 편집창으로 포커스를 강제 이동하거나 본문 끝으로 커서를 이동하지 않도록 변경했습니다.
- 기록물 편집 도구를 열고 닫을 때 이전 기록물의 위치와 화면 스크롤을 보존합니다.
- 폴라로이드 사진 영역을 눌러 사진을 고를 수 있고, 로고 사진·텍스트, 순서 이동, 삭제, 그림자·기울기 및 줄노트 너비·높이 설정을 지원합니다.
- 팔레트는 기본 빠른 색상 16개, 무채색 및 18개 색조 페이지(총 19페이지), HEX 입력, 사용자 색 저장·삭제, 저장 색 빠른 선택을 제공합니다.
- 선택 영역을 유지한 채 글자색과 형광펜을 적용하도록 개선했습니다.
- Markdown은 붙여넣기·직접 입력 뒤 자동 변환을 지원하며, 별도 Markdown 입력 패널에서 미리보기·본문 삽입·비우기도 할 수 있습니다.
- 실행 취소·다시 실행, 비밀글 암호화 및 기존 페어 로그 기능은 유지합니다.

[저장 데이터]

기존 저장 데이터를 삭제하거나 브라우저 저장소를 초기화하지 마세요.
