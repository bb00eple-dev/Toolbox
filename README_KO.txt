P. TOOLBOX v53 · MINIMAL PRETTY

배포
1. 기존 GitHub 저장소의 index.html과 sw.js를 v53 파일로 교체합니다.
2. 기존 manifest.webmanifest와 아이콘이 있다면 그대로 유지합니다.
3. LocalStorage 및 IndexedDB를 초기화하지 마세요. 기존 방/게시글/로그를 유지합니다.

v53 변경 사항
- Pair Log 읽기 화면을 전체 화면 독립 열람 레이아웃으로 재설계했습니다. 목록에서 로그를 누르면 바로 열립니다.
- 열람 스킨은 로그 작성/편집 단계에서 선택하고, 색상(바탕/글자/포인트)도 로그별로 저장합니다.
- 기본 에디토리얼 종이 스킨 포함 6개 스킨을 타이포그래피, 여백, 메타 정보 위계를 기준으로 새로 구성했습니다.
- 로그 제목은 크게, 날짜/태그는 작게 표시하며, 태그/분류는 박스 칩을 제거하고 상단 메타 라인으로 정리했습니다. 닫기 버튼은 테두리 없는 ×만 남겼습니다.
- PROMPT RANDOM 개별 랜덤 버튼을 작은 회전 아이콘으로 축소했습니다.
- THEME에서 격자/줄무늬/점/대각선 패턴의 투명 패턴 레이어를 분리해, 패턴이 베이스 컬러와 섞여 사라지던 문제를 수정했습니다.
- 메인 창 타이틀바 색, 창 프레임(기존 회색 바탕), 작업 바탕색, 패턴 선/사이 색을 각각 설정할 수 있습니다.
- Pair Board에 D-day와 페어 배너 사진(그라데이션/전체 배너, 투명도)을 추가했습니다.
- 프롬프트 버전 탭을 상세 화면 상단의 가로 스크롤 레일로 고정해, 선택한 버전을 보고 있어도 전체 버전 버튼이 남습니다.

주의
- 이미지 첨부는 Blob 형태로 기존 방 저장소에 저장됩니다. 데이터 초기화/마이그레이션을 수동 실행하지 마세요.
- 기존 로그는 새 디자인 설정이 없는 경우 기본 Editorial Paper 스킨으로 표시됩니다.
- 타 브라우저/기기에서의 터치 및 장시간 사용은 실제 배포 후 추가 확인이 필요합니다.
